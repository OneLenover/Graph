# Практические работы по графам

## Практическая работа №4

**Задача:** для двудольного графа найти паросочетание с оптимальным весом.

### Запуск
* `dotnet run` — встроенный пример (минимальный вес)
* `dotnet run -- input.txt` — граф из файла, минимальный вес
* `dotnet run -- input.txt max` — граф из файла, максимальный вес

### Формат входного файла

Вершины каждой доли нумеруются с 1.

Первая строка:

* `m m k` — размеры долей и количество рёбер.

Следующие `k` строк:

* `l r w` — вершина левой доли, вершина правой доли и вес ребра.


## Практическая работа №6

**Задача:** Для заданного графа проверить его планарность с помощью одного из алгоритмов комбинаторной укладки. Если он планарен, с помощью геометрической укладки нарисовать его.

### Запуск
* `dotnet run -- название.txt название.svg`

### Формат входного файла

Первая строка: 

* `n m` - количество вершин и ребер

Следующие m строк:

* `u v` с нумерацией вершин от 1

### Ограничения

* Для непланарного графа программа говорит только «не планарен» и называет блок, где это обнаружено. Явную подстановку K₅ или K₃,₃ (подграф Куратовского) она не строит.

* Рисунок строится только для двусвязного графа (без мостов и точек сочленения). Для остальных планарных графов программа сообщает, что граф планарен, но координаты не считает.
