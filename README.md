# Практические работы по графам

## Практическая работа №4

**Граф двудольный, в нём найти оптимальный вес паросочетания**

Запуск:
    - dotnet run - встроенный пример (минимум)
    - dotnet run -- input.txt - граф из файла, минимальный вес
    - dotnet run -- input.txt max - граф из файла, максимальный вес

Формат файла (вершины каждой доли нумеруется с 1):
    - m m k - размеры дулей и числой ребер
    - l r w - k строк: веришины левой доли, вершины правой доли, вес
