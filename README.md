# Практические работы по графам

## Практическая работа №4

**Задача:** для двудольного графа найти паросочетание с оптимальным весом.

### Запуск
* `dotnet run` — встроенный пример (минимальный вес)
* `dotnet run -- input.txt` — граф из файла, минимальный вес
* `dotnet run -- input.txt max` — граф из файла, максимальный вес

### Формат входного файла

Вершины каждой доли нумеруются с 1.

Первая строка:

* `m m k` — размеры долей и количество рёбер.

Следующие `k` строк:

* `l r w` — вершина левой доли, вершина правой доли и вес ребра.
